# Nika’s TradeTrack

პირადი სავაჭრო ჟურნალი — React, TypeScript, ადგილობრივი მონაცემების შენახვა.

## გაშვება კომპიუტერზე

საჭიროა Node.js 22.13 ან უფრო ახალი ვერსია.

```sh
npm install
npm run dev:local
```

გახსენით ტერმინალში ნაჩვენები მისამართი. პროექტი ZIP-იდან ჯერ სრულად ამოარქივეთ.

## უკვე აწყობილი საიტი

`dist-static` შეიცავს მზა სტატიკურ საიტს. განათავსეთ ამ საქაღალდის შიგთავსი სტატიკურ ჰოსტინგზე (მაგალითად GitHub Pages-ზე). ლოკალურად გამოიყენეთ HTTP სერვერი; `index.html`-ზე ორმაგი დაჭერით ES modules არ გაეშვება.

```sh
npm run build:static
npm run preview:static
```

ორიგინალი Sites კონფიგურაცია შენარჩუნებულია. ჩვეულებრივი კომპიუტერისთვის გამოიყენეთ ზემოთ მითითებული `:local` და `:static` ბრძანებები.

## ფუნქციები

- დახურული ტრედების დამატება, ნახვა, რედაქტირება და დადასტურებით წაშლა.
- წმინდა P&L, საკომისიოები, პოზიციის რაოდენობა, კონტრაქტის მულტიპლიკატორი და ხელით შეყვანილი წმინდა შედეგი.
- დაგეგმილი R:R, საწყისი ფასობრივი რისკი, საშუალო რეალური R, expectancy და დახურული ტრედების მაქსიმალური ვარდნა.
- კალენდრიდან დღეზე გადასვლა, პერიოდები, ძიება აქტივში/შენიშვნებში/სეტაპებში, ფილტრები და სორტირება.
- CSV ექსპორტი ზუსტად გაფილტრული ტრედებისთვის; JSON სრული სარეზერვო ასლი და დადასტურებით აღდგენა.
- მიზნები, დღიური ჩეკლისტი, სავაჭრო წესები და წესების დარღვევები.
- ეკრანის სურათები HTTPS ბმულით ან PNG/JPEG/WebP ატვირთვით (500 KB-მდე).
- ლოგო აბრუნებს მთავარზე; Ctrl/⌘ + Enter ხსნის ტრედის ფორმას; `/` გადადის ძიებაზე.
- გვერდების, ბარათების, დიაგრამის, პროგრესის და ღილაკების ანიმაციები. Settings-იდან გამორთვა და სისტემის reduced-motion მხარდაჭერა.

## მონაცემები და გამოთვლები

ინფორმაცია ინახება მხოლოდ ამ ბრაუზერის ამ მისამართის localStorage-ში. სხვა მოწყობილობაზე ან მისამართზე გადასატანად გამოიყენეთ JSON ექსპორტი/აღდგენა. ანგარიშის სინქრონიზაცია, ბროკერთან კავშირი და ცოცხალი ფასები არ არის ჩართული. მონაცემების წაშლამდე აუცილებლად შეინახეთ JSON backup.

P&L = (exit − entry) × მიმართულება × რაოდენობა × USD მულტიპლიკატორი − საკომისიო; შედეგი მრგვალდება ცენტამდე. Short მიმართულებისთვის ნიშანი არის −1. Override უკვე წმინდა USD შედეგია და საკომისიო მეორედ არ აკლდება. ფასობრივი რისკი არ მოიცავს საკომისიოს; რეალური R = net P&L / საწყისი ფასობრივი რისკი. Win rate-ის მნიშვნელი მოიცავს break-even ტრედებს. Drawdown ითვლება არჩეულ პერიოდში დახურული ტრედების თანმიმდევრობიდან; დღის შიგნით შესრულების დრო არ ინახება, ამიტომ ერთი დღის შიდა ზუსტი drawdown არ გამოითვლება. Account growth აჩვენებს ყველა დროის შედეგს.

პირველ გახსნაზე მონაცემები დემონსტრაციულია და მონიშნულია. Start my journal შლის მხოლოდ demo ტრედებს; მიზნების საწყისი მაგალითები შეგიძლიათ წაშალოთ ან შეცვალოთ პროგრესი.
